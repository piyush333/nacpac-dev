NACPAC LANDING PAGE — DESIGN & BUILD CONTEXT
For handoff to Claude Design / continuation sessions
============================================================

PROJECT
-------
NACPAC is an in-house print studio in India.
Three product lines: Stickers, Wallpapers, NTR (Number-Tag-Rolls).
Primary customer acquisition channel: WhatsApp.
The landing page (web/) is a static HTML/CSS/JS site — no framework, no build step.
Served locally via: python3 -m http.server 3457 --directory web

Files:
  web/index.html   — full page markup
  web/styles.css   — complete design system + component styles
  web/main.js      — scroll-reveal, animated counters, 3D card tilt, mobile nav, sticky header

ANIMATIONS
----------
Scroll reveal:
  All major elements have [data-reveal] attribute
  IntersectionObserver in main.js adds .is-visible class on enter
  CSS: opacity 0 → 1, translateY(28px) → 0, duration .7s, ease-out cubic
  data-delay="1/2/3/4" adds transition-delay of .1/.2/.3/.4s

Animated counters:
  Elements with data-count="12000" data-suffix="+" start at 0
  requestAnimationFrame loop with cubic ease-out over 1800ms
  Triggers when element enters viewport (IntersectionObserver threshold 0.5)

3D card tilt:
  .tilt-card class — mousemove applies perspective(600px) rotateY/rotateX
  Rotates ±5deg on both axes based on mouse position within card
  Resets on mouseleave

Marquee:
  .strip-track — animation: marquee 28s linear infinite
  Track is duplicated (20 items × 2 = 40 spans) for seamless loop
  translateX(0) → translateX(-50%)

Floating badge:
  @keyframes float — translateY(0) ↔ translateY(-8px), 3s ease-in-out infinite

Pulse dot (urgency tag in CTA banner):
  @keyframes pulse — scale + opacity, 1.5s, on green 8px circle

Sticky header:
  window scroll listener (passive) adds .is-scrolled class at >20px
  .is-scrolled adds border-bottom + box-shadow


MOBILE RESPONSIVENESS
---------------------
Breakpoints used:
  860px — hero becomes 2-col, desktop nav shows, burger hides, header phone/CTA shows
  750px — product grid becomes 3-col, testimonials 3-col, footer 4-col
  600px — features grid becomes 2-col

Key mobile-specific decisions:
  - Header CTA button (.header-cta) is hidden at ≤859px (was causing horizontal overflow)
  - Hero stacks to single column
  - H1 uses clamp(2.4rem, 5.5vw, 4.8rem) to prevent word-break on narrow screens
  - Mobile nav: fullscreen overlay, slides from top, visibility:hidden when closed
    (visibility trick prevents tab-focus on hidden links)

Verified clean at:
  - 375px (iPhone SE) — no horizontal overflow, scrollWidth === 375
  - 1280px desktop — all 10 sections render correctly

REPO CONTEXT
------------
This web/ folder is one of four parts of the NACPAC monorepo:
  mobile/   — Expo/React Native admin app (~80% complete)
  desktop/  — Electron/React operator dashboard (~20% complete)
  shared/   — TypeScript types (Job, Client, status enums)
  web/      — this landing page (complete, needs real contact data)

Firebase is the shared backend:
  Firestore collections: clients, jobs, jobFiles
  Firebase Storage for file uploads from mobile admin
  Auth: email/password
