# nacpac.in

Website concepts + assets for **NacPac** — custom sticker printing & packaging for small businesses in India.

## Concepts

| File | Direction |
|---|---|
| `concept-a-playful.html` | Playful, Tapey-led, chunky shadows — small-biz friendly |
| `concept-b-premium.html` | Premium minimal, editorial, studio feel |
| `concept-hybrid.html` | Hybrid of A + B — warm but professional |
| `concept-v2.html` | **Current direction.** Hybrid refined after competitor analysis — adds live price calculator, Tapey mascot throughout, Google Reviews badge, ₹99 sample pack, FAQ accordion, email capture |
| `tapey.html` | Tapey mascot reference (original SVG + animations) |

## Brand

- **Palette:** Purple `#5a3493` · Deep purple `#29266c` · Yellow `#f5b11b` · Lavender `#dccee6`
- **Type:** Futura (Jost as open-source fallback)
- **Mascot:** Tapey — animated tape-roll character

## Stack (planned)

- Frontend: Custom HTML/CSS (will port into WP theme)
- Backend: WordPress + WooCommerce
- File storage: Cloudflare R2 (customer-uploaded design files)
- Factory integration: Local factory app polls Woo REST API for new orders
